## About

I am a software engineer with a BCA (Honours) from CHRIST University, focused on building reliable, scalable and user-centric products. My work spans the full stack: responsive React interfaces, headless Shopify storefronts, Firebase-backed services and machine learning pipelines that turn data into decisions.

- **Software engineering first:** clean architecture, maintainable code and disciplined version control.
- **AI / ML:** data science and machine learning experience from an internship at YBI Foundation and a co-authored HR-ML research paper.
- **Full stack development:** JavaScript, React, Node.js, Firebase and Next.js, with third-party API integration (TMDB, Shopify Storefront API).
- **Product engineering mindset:** I care about the user problem, delivery speed and measurable impact, not only the code.
